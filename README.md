# Язык «Рошан»

Учебный язык программирования в стиле Dota 2. Программы хранятся в файлах с расширением `.dota`.

Сейчас готов **лексер**: он разбивает программу на токены. Дальше по курсовой будут парсер и перевод в ассемблер NASM.

## Словарь

| В обычном языке | В «Рошане» | Почему |
|---|---|---|
| начало / конец программы | `пик` … `гг` | матч начинается с пика и заканчивается «gg» |
| переменная | `герой` | |
| константа | `аегис` | аегис не умирает, значение не меняется |
| массив | `инвентарь` | инвентарь героя — набор слотов |
| `if` / `else` | `вард` / `туман` | вард даёт обзор, туман — всё, что не видно |
| `while` | `фармить` | фармим, пока условие выполняется |
| `for` | `волна` … `до` | крипы идут волнами |
| функция | `скилл` | |
| `return` | `тп` | телепорт обратно на базу |
| вывод | `пинг` | пинг на карте видят все |
| ввод | `закуп` | закупаем значение с клавиатуры |

## Операторы

| Оператор | Значение | Приоритет |
|---|---|---|
| `( )`, вызов `f(x)`, индекс `a[i]` | | 1 (выше всех) |
| `урон x`, `не x` | минус перед числом, логическое НЕ | 2 |
| `крит`, `сплит`, `ласт` | `*`, `/`, `%` | 3 |
| `хил`, `урон` | `+`, `-` | 4 |
| `<  <=  >  >=` | сравнение | 5 |
| `==  !=` | равно, не равно | 6 |
| `и` | логическое И | 7 |
| `или` | логическое ИЛИ | 8 (ниже всех) |

Символов `+ - * / %` в языке нет: арифметика пишется только словами.

## Правила

- Все числа целые, 32 бита (от −2147483648 до 2147483647).
- Сравнения дают 1 (правда) или 0 (ложь). В условии любое ненулевое значение — правда.
- Массив: `инвентарь имя[размер];`. Размер — число, индексы с 0, элементы сначала равны 0.
- `волна i = 1 до 10 { ... }` — цикл от 1 до 10 включительно, шаг 1. Счётчик `i` создаётся самим циклом.
- Функции объявляются до `пик`. Параметры и результат — целые числа. Без `тп` функция возвращает 0.
- `пинг` выводит число или строку в кавычках и переходит на новую строку. Внутри строки можно писать `\"` и `\n`.
- Комментарий — от `//` до конца строки.
- Имена: русские и латинские буквы, цифры и `_`, но не с цифры. Большие и маленькие буквы различаются.

## Примеры

**Факториал** — [`examples/factorial.dota`](examples/factorial.dota):

```
скилл факториал(n)
{
    герой итог = 1;
    фармить (n > 1)
    {
        итог = итог крит n;
        n = n урон 1;
    }
    тп итог;
}

пик
    герой x;
    закуп x;
    вард (x < 0)
    {
        пинг "Отрицательное число, репорт";
    }
    туман
    {
        пинг факториал(x);
    }
гг
```

**Массив и цикл со счётчиком** — [`examples/inventory.dota`](examples/inventory.dota):

```
пик
    инвентарь цены[6];
    герой сумма = 0;

    волна i = 0 до 5
    {
        цены[i] = (i хил 1) крит 500;  // 500, 1000, ..., 3000
    }

    волна i = 0 до 5
    {
        сумма = сумма хил цены[i];
    }

    пинг "Стоимость инвентаря:";
    пинг сумма;                        // 10500
гг
```

Ещё примеры:
- [`examples/arithmetic.dota`](examples/arithmetic.dota) — все операторы, константа, функция с двумя параметрами, цепочка `вард … туман вард … туман`;
- [`examples/errors.dota`](examples/errors.dota) — программа с лексическими ошибками.

## Грамматика (РБНФ)

```
программа    = { функция } "пик" { оператор } "гг" ;
функция      = "скилл" ИМЯ "(" [ ИМЯ { "," ИМЯ } ] ")" блок ;
блок         = "{" { оператор } "}" ;

оператор     = переменная | константа | массив | присваивание | условие
             | пока | волна | возврат | вывод | ввод | вызов ";" ;
переменная   = "герой" ИМЯ [ "=" выражение ] ";" ;
константа    = "аегис" ИМЯ "=" выражение ";" ;
массив       = "инвентарь" ИМЯ "[" ЧИСЛО "]" ";" ;
присваивание = место "=" выражение ";" ;
место        = ИМЯ [ "[" выражение "]" ] ;
условие      = "вард" "(" выражение ")" блок [ "туман" ( блок | условие ) ] ;
пока         = "фармить" "(" выражение ")" блок ;
волна        = "волна" ИМЯ "=" выражение "до" выражение блок ;
возврат      = "тп" [ выражение ] ";" ;
вывод        = "пинг" ( выражение | СТРОКА ) ";" ;
ввод         = "закуп" место ";" ;
вызов        = ИМЯ "(" [ выражение { "," выражение } ] ")" ;

выражение    = и_выраж { "или" и_выраж } ;
и_выраж      = равенство { "и" равенство } ;
равенство    = сравнение { ( "==" | "!=" ) сравнение } ;
сравнение    = сумма { ( "<" | "<=" | ">" | ">=" ) сумма } ;
сумма        = произв { ( "хил" | "урон" ) произв } ;
произв       = унарное { ( "крит" | "сплит" | "ласт" ) унарное } ;
унарное      = ( "урон" | "не" ) унарное | первичное ;
первичное    = ЧИСЛО | вызов | место | "(" выражение ")" ;
```

## Лексер

Лексер читает файл `.dota` и выводит таблицу токенов: позиция (строка:столбец), лексема, категория, смысл.

| Категория | Что сюда входит |
|---|---|
| ключевое слово | `пик гг герой аегис инвентарь вард туман фармить волна до скилл тп пинг закуп` |
| оператор | `хил урон крит сплит ласт и или не`, `= == != < <= > >=` |
| разделитель | `; , ( ) { } [ ]` |
| идентификатор | имена переменных, функций и массивов |
| число | целое от 0 до 2147483647 |
| строка | текст в двойных кавычках |

Пробелы, переводы строк и комментарии лексер пропускает.

Какие ошибки он находит (и не останавливается на первой):
- символы `+ - * / % !` — с подсказкой, каким словом их заменить;
- имя, начинающееся с цифры (`5крипов`);
- число больше 2147483647;
- незакрытая строка;
- неизвестный символ (`@`, `€` и т. п.).

### Сборка и запуск

**Visual Studio (Windows):**

1. **Файл → Создать → Проект → «Пустой проект» (C++)**.
2. Скопировать папки `src` и `examples` в папку проекта (ПКМ по проекту → «Открыть папку в проводнике»).
3. Добавить файлы в проект:
   - ПКМ по «Исходные файлы» → **Добавить → Существующий элемент** → `main.cpp`, `lexer.cpp`, `token.cpp` из `src`;
   - так же в «Файлы заголовков» → `lexer.h`, `token.h`.
4. ПКМ по проекту → **Свойства** → вверху «Конфигурация: **Все конфигурации**» → **C/C++ → Командная строка → Дополнительные параметры** → `/utf-8`. Без этого флага сборка остановится с ошибкой `Compile with /utf-8`.
5. **Ctrl+F5**. Программа спросит путь, ввести `examples\factorial.dota`.

**Linux / WSL / MinGW:**

```bash
g++ -std=c++17 -Wall -o lexer src/main.cpp src/lexer.cpp src/token.cpp
./lexer examples/factorial.dota
```

Если запустить без параметра, программа сама спросит путь к файлу.
