# Лабораторная работа №3. Команды передачи управления

Генерируем случайные числа от 0 до 65535 и раскладываем их по массиву `data` (512 слов):

- чётные → `data[0..127]`
- нечётные → `data[128..255]`
- ≥ 50000 → `data[256..383]`
- < 10000 → `data[384..511]`

Повторяем, пока в одной из групп не станет больше 127 чисел.

Массив выводится в терминал и записывается в файл [seed.txt](seed.txt): 4 строки, по одной на группу.
Нули `00000` в конце строки — незаполненные ячейки группы.

## Запуск

```bash
nasm -f elf32 lab3.asm -o lab3.o
ld -m elf_i386 lab3.o -o lab3
./lab3
```
